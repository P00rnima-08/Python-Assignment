Project Description : 
This project demonstrates how to integrate multiple AI APIs using Python to retrieve to send prompts and retrieve responses from various AI models. This includes implementations for Google Gemini, Groq, Cohere, HuggingFace and Ollama. Each Python program sends a prompt to the respective API and displays the generated response.

Setup Instructions :

1. Clone the repository:

git clone https://github.com/username/repo-name
cd ai-api-integration

2. Install required dependencies:

pip install -r requirements.txt

3. How to Obtain API Keys

Groq: https://console.groq.com
Cohere: https://dashboard.cohere.ai/api-keys
Google Gemini: https://makersuite.google.com/app/apikey
HuggingFace: https://huggingface.co/settings/tokens
Ollama does not require an API key (runs locally)

4. Set up API keys as environment variables:

For Windows (PowerShell):

$env:GROQ_API_KEY="your_api_key"
$env:COHERE_API_KEY="your_api_key"
$env:GOOGLE_API_KEY="your_api_key"
$env:HUGGINGFACE_API_KEY="your_api_key"

5. Run any Python file:

python gemini_example.py
python groq_example.py
python huggingface_example.py
python cohere_example.py
python ollama_example.py
